# ⭐ Catch The Star Game

## About the Project

Catch The Star is a simple and interactive browser-based game developed using HTML, CSS, and JavaScript.

The objective is to catch as many stars as possible within 30 seconds.

## 🎮 Features

- 30-second countdown timer
- Score tracking
- High Score using Local Storage
- Level progression
- Start, Pause, Resume and Restart controls
- Sound ON/OFF option
- Keyboard controls
- Responsive mobile design
- Accessibility support

## 🕹️ How to Play

1. Click the Start button.
2. Catch the moving star to increase your score.
3. Press SPACE to catch the star.
4. Press P to pause or resume.
5. Press M to mute or enable sound.
6. Try to achieve your highest score within 30 seconds.

## 🛠️ Technologies Used
