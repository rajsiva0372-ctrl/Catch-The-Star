# ⭐ Catch the Star Game

## About the Project

Catch the Star is a simple and interactive browser-based game. Players earn points by clicking stars within a 30-second time limit.

## Objective

Catch as many stars as possible before the timer reaches zero.

## Technologies Used

- HTML
- CSS
- JavaScript

## Game Features

- Interactive star clicking
- Live score tracking
- 30-second countdown timer
- Random star positioning
- Game Over notification

## How to Play

1. Open the game.
2. Click the Start Game button.
3. Click the star to increase your score.
4. Try to get the highest score within 30 seconds.
